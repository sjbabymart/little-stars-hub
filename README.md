# Little Stars Hub

PROJECT: S & J BABY MART + NJAU CHILDREN'S CLINIC

Design and develop a premium, modern, highly responsive website for:

S & J BABY MART

with an integrated healthcare section for:

NJAU CHILDREN'S CLINIC

The website combines:

A physical + online baby/children's clothing store.

An online e-commerce shopping system.

Product checkout and order management.

Delivery information and order processing.

Children's fashion / red-carpet photography showcase.

A professional children's clinic section operated as Njau Children's Clinic.

The final website must look like a premium Kenyan children's retail and healthcare brand — trustworthy, warm, modern and professional.

Do NOT make it look like a generic e-commerce template.

Create a temporary professional brand identity for the website using:

S & J BABY MART
